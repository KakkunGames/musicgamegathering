# 🎵 音楽ゲームの集い - 公式WEBサイト

Discordサーバー「音楽ゲームの集い」の公式Webサイトです。  
Cloudflare Pages × Cloudflare Workers を活用し、Discord OAuth2認証を導入しています。
Website：https://musicgamegathering.pages.dev

---

## 🌟 主な機能
- **Discord OAuth2ログイン**: Discordアカウントを使って安全にログイン
- **ユーザー情報表示**: ログイン中のユーザー名・アイコンの表示
- **高速な静的ホスティング**: Cloudflare Pagesによる高速レスポンス

---

## 🛠️ 使用技術
- **Frontend**: HTML5 / CSS3 / JavaScript (ES6+)
- **Hosting**: Cloudflare Pages
- **Backend / Auth**: Cloudflare Workers (Discord OAuth2 API)

---

## 🚀 ローカル開発・デプロイ
1. リポジトリをクローン
2. `index.html` を編集
3. GitHubへPushするとCloudflare Pagesへ自動デプロイ
